# 产品需求文档（PRD）— 消防安全训练平台

**版本**：v1.0  
**日期**：2025-03-11  
**状态**：初稿

---

## 一、项目概述

### 1.1 项目名称
消防安全训练平台

### 1.2 项目目标
打造一款面向消防培训场景的互动学习平台，通过游戏化方式提升用户消防安全知识与应急技能，支持多款消防主题小游戏，并提供排行榜与个人成长体系以增强参与度。

### 1.3 目标用户
- 企业/学校消防安全培训学员  
- 对消防知识有学习需求的普通用户

|----------|----------|----------|
| F1.1     | 展示平台内所有消防主题游戏入口 | 以列表或卡片形式展示，每项包含游戏名称、简要描述、封面图（可选） |
| F1.2     | 支持点击某一游戏 | 点击后跳转至该游戏的「游戏首页」 |
| F1.3     | 全局导航 | 提供入口：首页、排行榜、个人主页，各页面可一致展示 |

## 五、积分机制与数据口径

### 5.1 积分口径（基础规则）
- **基础分**：按关卡完成、题目正确、关键操作完成等累积分值。  
- **时间加成/扣分**（可选）：耗时越短加成越高，超时扣分。  
- **安全规范加成/扣分**（可选）：错误操作扣分。  
- **失败/重试策略**（可选）：失败可给部分分或 0 分。

### 5.2 成绩上报与排行榜入榜规则
- **成绩记录**：每次游戏结束生成一条成绩记录（用户ID、游戏ID、得分、耗时、时间戳等）。  
- **入榜口径**：单局最高分或累计积分，可设周期（日/周/月/总）。  
- **并列名次规则**：同分按用时更短排前；仍相同按更早达成时间排前。

### 5.3 部门字段口径
- **字段**：部门名称（必填展示项，若无则显示“未分配部门”）、部门编码/ID（可选）。  
- **一致性**：个人主页、排行榜、成绩记录中的部门字段保持同一来源与同一口径。

## 六、用户流程简述

### 6.1 从首页进入并开始游戏
1. 用户打开平台 → 看到**首页游戏列表**  
2. 点击某一游戏 → 进入该游戏的**游戏首页**  
3. 在游戏首页点击「**开始游戏**」→ 进入**游戏内**  
4. 游戏结束 → 查看结果，可选择「再玩一局」或「返回游戏首页」/「返回首页」

### 6.2 查看排行榜
1. 在任意底部 Tab 页面点击「排行榜」→ 进入**排行榜**  
2. 查看名次与分数，可选切换不同游戏或全局榜  
3. 通过底部 Tab 返回首页或个人主页  

### 6.3 查看个人主页
1. 在任意底部 Tab 页面点击「我的」→ 进入**个人主页**  
2. 查看个人信息与成绩/成就  
3. 通过底部 Tab 返回首页或进入某款游戏

## 七、非功能需求（建议）

| 类型     | 说明 |
|----------|------|
| 兼容性   | 支持主流浏览器（Chrome、Safari、Edge 等） |
| 设备     | **移动端优先**（iOS/Android），适配不同屏幕尺寸与安全区 |
| 交互     | 支持手势返回（iOS）、Android 返回键与页面栈一致 |
| 性能     | 首屏加载时间、列表渲染时间可设目标值（如 3s 内） |
| 扩展性   | 游戏列表与游戏类型可配置或可插拔，便于后续新增游戏 |
| 数据     | 若需持久化成绩与排行榜，需明确是否要后端与登录（当前可先做前端 mock） |

### 7.1 视觉与主题
- **主题色**：整体采用主色 **#0064ff**，用于按钮、链接、高亮、Tab 选中态等；半透明主色用于背景、描边时与主色保持一致（如 `rgba(0,100,255,...)`）。  
- 具体 UI 与组件规范见前端技术方案中的样式与 UI 规范章节。
